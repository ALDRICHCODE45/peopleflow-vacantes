# Careers builder polish

Second-round UX polish of the careers-site builder after the user's first hands-on review
(2026-10-27). Frontend branch `feat/careers-builder-polish` from main `a7413176`. Contract
changes (icons/emoji, palette) are coordinated with backend session `01a16b3c`.

## Specs

- **S1 Save failure is visible and recoverable.** User: «no se por que no me deja publicar el sitio, en algun punto, ya no se guardaron los datos automaticamente, me aparece un mensaje de "no se pudieron guardar los cambios" y no veo algo para guardar los cambios manualmente, ni tampoco veo nada en la pestana de network que me pueda ayudar». A draft that fails local schema validation (e.g. over-limit text, non-HTTPS map URL) must mark the offending field(s) («Revisa los campos marcados»), never the generic error; any remaining generic save error offers a manual retry; publishing stays possible once the draft is fixed.
- **S2 Icon picker alignment.** User: «la seccion de los iconos hay dos cosas que corregiria, lo primero es que esta rara, el efecto hover el icono esta raro, es como si los iconos esten alineados a la izquierda en lugar de en el centro». Icons centred in their cells; selection shown without shifting the glyph.
- **S3 More icons and emojis.** User: «y tambien agregaria muchos mas iconos e incluso meteria emojis». Decision (L2): «Ícono o emoji (Recomendado)» — each item uses either a library icon or an emoji. Contract change on both sides.
- **S4 Brand palette.** User: «me gustaria evaluar la posibilidad de llevarlo al siguiente nivel, algo asi como "color principal" "secundario" "acento/cta" "fondo(no se, es una idea)" " texto secundario", y yo se que esto, para el usuario eleva un poco la complejidad, y es por eso que me gustaria tener opciones preseteadas de paletas de colores, pero todo debe funcionar bien». Decision (L2): «Paletas + 3 colores (Recomendado)» — preset palettes with guaranteed contrast plus «Personalizar» with principal, acento/CTA and fondo; secondary text derived automatically.
- **S5 Resizable, collapsible editor panes.** User: «lo que se me ocurre es agregar capacidad para hacer un "resize" de cada seccion, sidebar derecho, izquierdo e incluso el editor, aprovechando el componente de shadcn creado para eso: https://ui.shadcn.com/docs/components/base/resizable y tambien algo que me gustaria mucho es que los "dos sidebars" se puedan minimizar».
- **S6 Right panel not crushed.** User: «especificamente en el sidebar derecho en donde tienes que poner el contenido, haay ciertas cosas que estas bastante aplastadas sin importar el tamano del monitor». Item rows (title, menu, chevron) must not truncate/overlap at the default width.
