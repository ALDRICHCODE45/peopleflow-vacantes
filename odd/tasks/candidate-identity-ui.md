## Specs
- S1. User decisions relayed by the backend: «Mismo user pool de Cognito; el rol vive en nuestra base y el backend lo exige por ruta.»; «Una cuenta tiene un solo rol: quien quiera ser reclutador y candidato usa dos emails.»; «Registro e ingreso con email y contraseña vía el login alojado de Cognito, como el reclutador. Google y LinkedIn quedan para después.»; no own app client: «Mismo pool y mismo app client, con tu único provider de NextAuth.» Standing rules: docs/frontend-ui-design-rules.md + shadcn; review queue; nothing merged without the user's test.
- S2. `GET /v2/me` (Bearer) → `{role: "recruiter"|"candidate"|null, user: {id, email, full_name}|null}`, user null exactly when role null; strict keys. Guards use only this, never the company-route codes (company routes: token without account → 401 unauthenticated; candidate account → 403 forbidden).
- S3. `POST /v2/me/candidate-account` {full_name} → 201 created or 200 already candidate (safe retry), body exactly the GET /v2/me shape. Errors: 409 account_exists (already recruiter), 409 email_in_use, 422 email_not_verified, 400 validation_error (name), 503 identity_unavailable. The email is never sent by the browser.
- S4. Candidate routes return 403 account_required (valid token, no account → onboarding) and 403 wrong_role (recruiter account). A wrong onboarding cannot be undone in this cut.
- S5. UI: real sign-in/sign-up at /candidato/login with the same NextAuth provider; after sign-in a router sends candidate → /candidato/dashboard, no account → onboarding, recruiter → «Esta cuenta es de empresa» with an exit; onboarding is only offered inside the candidate flow, shows «Vas a crear una cuenta de candidato con {email}. Esta cuenta no podrá usarse para publicar vacantes.» (email from the NextAuth session only for display) and an explicit «Crear mi cuenta de candidato» button that never fires by itself; /empresa with an authenticated session: role null → «Esta cuenta todavía no tiene acceso a empresa» with an exit to /candidato/login, role candidate → «Esta cuenta es de candidato»; candidate session with refresh, logout back to /candidato/login (strict allowlist, no open redirect), candidate user menu with real name and email.
