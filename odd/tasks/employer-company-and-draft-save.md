Backend contract (session 01a13bd9-05b4, branch 161fb2f, read-only report): `GET /industries` public → 200 direct array `[{"id":string,"label_es":string,"label_en":string,"sort_order":int}]` (active only, ordered). `POST /companies` (Bearer) body min `{"name","rfc","industry_id"}`; 201 companyResponse `{id,name,rfc,industry_id,status, optional omitempty fields, created_at, updated_at}`; errors `{"error":string,"code":string}`: 401 unauthenticated, 403 forbidden (not recruiter), 400 invalid_request (Spanish domain message in `error`, display only), 409 industry_unavailable, 409 already_exists (duplicate RFC or creator already has membership), 413. Drafts v2 per docs/contracts/private-vacancy-drafts-v2-screening.md and api/client-v2.md; drafts need company status `active` (else 409 company_not_active, 403 company_inactive). No endpoint redirects; treat 3xx as error. Token: Cognito access token by client_id; ID token never sent.

Fail closed without a usable session. No automatic mutation retries; an uncertain create keeps its Idempotency-Key so an explicit user retry replays. No sample/mocked success; Sileo success only after a confirmed backend result.
