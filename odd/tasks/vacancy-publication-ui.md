- S3. Management resource GET/PUT `/v2/me/company/job-drafts/{draftId}/management`: `{"version", "requestDate": "YYYY-MM-DD"|null, "hiringHeadcount": int|null, "limits":{"maxHiringHeadcount"}, "today": "YYYY-MM-DD"}`; PUT body exactly `{requestDate, hiringHeadcount}` (both required, nullable); cut-3 conventions; a changed date must be <= today (any weekday); unchanged stored values accepted.
- S4. Readiness GET `/v2/me/company/job-drafts/{draftId}/publication` → `{"status": "draft"|"published", "publishedAt": RFC3339|null, "missing": [codes]}`. Codes (stable order): title_missing, description_missing, location_missing, work_mode_missing, work_schedule_missing, contract_type_missing, professional_area_missing, requester_missing (draft editor); request_date_missing, hiring_headcount_missing (management); delivery_cutoff_missing, delivery_target_missing, commitment_date_missing, commitment_date_past (delivery). Unknown code → generic missing item, never a crash.
- S5. Publish POST same path, body `{}`, Idempotency-Key + If-Match (draft ETag) → 201 `{"id", "status":"published", "publishedAt"}` (same id). Errors: 422 publication_incomplete `{error, code, missing}` (only envelope with a list), 409 already_published, 409 idempotency_conflict, 412 version_conflict, 428 precondition_required, plus §4.
- S6. Portfolio list items gain `status` (draft|published) and `published_at` (RFC3339|null).
- S7. UI: «Solicitud» configuration sub-module (/configuracion/solicitud) for request date + headcount; «Publicar» in the draft editor review step, the portfolio row «Acciones» menu and the draft pipeline empty state; the publish dialog loads the draft (ETag + summary) and readiness, shows «Te falta para publicar» with links to where each item is completed, or a confirmation summary (commitment date, target, cutoff column) warning that publishing starts the delivery clock; after publishing the row shows «Activa» + «Publicada el …» (out of the Borradores tab) and the pipeline page shows the empty board instead of «todavía no tiene pipeline».
