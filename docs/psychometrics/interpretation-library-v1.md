## Rendering and storage

The backend resolves the row from stored bands, not from mutable UI labels. Store library id and selected text snapshot with the result and its content version. Same version and inputs produce byte-identical wording. A later content revision never silently changes an existing report. A new job profile can create a new explicit comparison snapshot, but does not rewrite the assessment's library selection. No clinical interpretation, observed-performance assertion or automatic outcome may be generated from these entries.
