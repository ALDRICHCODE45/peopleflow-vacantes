**Locked decisions NOT to re-open** (design §2 table):
- **D7** — `name = *string`; all 12 profile columns use `Optional[T]` tri-state (this overrides the proposal §6.2 wording that suggested plain `*string` for text columns — the spec is explicit that absent vs JSON-null must be distinguished for every profile column, and a plain `*string` cannot decode the JSON-null case).
- **D8** — `CompanyEditorViewDto` is a **new, distinct DTO** that omits `industry_id`, `rfc`, `status`, `deleted_at`, `created_at` (this overrides the proposal §4.11 / §6.12 wording that suggested reusing `companyPublicResponse` — the existing public shape **does** expose `industry_id`, contradicting the spec's `MUST NOT include industry_id`).
- **D10** — `buildUpdateCompanyParams` arg order is **SET-list first, then WHERE** (`company_id`, `cas_token` last). This OVERRIDES the proposal §14.5 wording that placed `company_id` first (which held only for jobs because of the jobs `active` CTE; companies has no active-company guard, so the SET list textually precedes the WHERE in the SQL).
- **D15** — `NewCompanyService(repo)` is UNCHANGED; the adapter becomes pool-owning (`NewCompanyRepository(pool)`) and owns its own `pgx.Tx`. This OVERRIDES the proposal §7.2 wording that suggested `NewCompanyService(repo, pool)`.
- **D5** — `CloseCompanyJobs :execrows` (NOT `:exec`) so `RowsAffected` is surfaced as telemetry; the use case does NOT branch on it.
- **D9** — new `companies/domain/entities/sentinels.go` owns `ErrConcurrencyConflict` + `ErrInvalidCompanyStatusTransition`; `company.go` stays byte-for-byte unchanged (the proposal's "NO CHANGE" is honored literally — a new file is additive).
