# Checklist de la vacante (R9 / S5)

Tres direcciones para `/empresa/vacantes/[jobId]/configuracion/checklist`. Solo usan capacidades reales de
`frontend/src/features/vacancy-checklist/editor/`: ocho tipos de criterio, Obligatorio / Deseable, diálogo de criterio,
subir, bajar y quitar, agregar hasta 50, recordatorio al mover, Guardar / Descartar.

- 01 Lista agrupada (recomendada)
- 02 Lista y detalle
- 03 Tabla por tipo

Datos: siete criterios reales de Software Developer; años, escolaridad, pregunta de filtro y criterio manual son
ilustrativos, igual que los nombres de etapas. Los prototipos no guardan datos.
